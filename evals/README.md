# Evals

`golden.jsonl` is the golden question set: one JSON object per line, ids `g01` through `g18` in order. Each line has `id`, `question`, `kind`, `expect_grounded`, `must_contain`, and `reference`. `kind` is one of `grounded` (answerable only from a single document in `data/corpus/`), `multi` (asks two distinct things that live in two different corpus documents), `web` (general knowledge the corpus cannot answer, with a stable well-known answer), or `metadata` (a question about the document set itself, such as "What documents do I have?"). `expect_grounded` is `true` for `grounded` and `multi` and `false` for `web` and `metadata`. `must_contain` is a list of one or two short substrings; an answer passes only if every substring appears in it, compared case-insensitively. `reference` is a one-sentence ideal answer used for human review, not for exact matching. Beyond the substring check, `grounded` and `multi` answers are expected to carry document citations pointing into the corpus, while `web` answers are expected to carry web citations rather than document citations.

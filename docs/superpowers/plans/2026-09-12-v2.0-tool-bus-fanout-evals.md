# Groundscope v2.0 Implementation Plan (tool bus, fan-out, evals-in-CI)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v2.0 of Groundscope: one MCP tool bus (three servers), parallel query fan-out visible in the trace, and an LLM-judged eval gate enforced in GitHub Actions.

**Architecture:** Three stdio FastMCP servers (`retrieval`, `web`, `utils`) are loaded by one registry into a `ToolBus`. The LangGraph supervisor decomposes a knowledge question into at most 3 sub-queries, fans them out with `Send` to parallel `retrieval_worker` nodes (each runs a per-branch corrective gate: docs, then web), aggregates, and synthesizes. `evals/` runs a golden set through the graph and scores it with a custom Groq judge; CI runs lint, typecheck, tests, evals (against a pgvector service container), and a docker build.

**Tech Stack:** Python 3.12, FastAPI, LangGraph 0.2.39, langchain-mcp-adapters 0.1.7, mcp 1.27.2 (FastMCP), psycopg + pgvector, fastembed, Groq (OpenAI-compatible), Tavily, pytest, ruff, pyright, GitHub Actions.

**Spec:** `docs/v2-roadmap.md`, `docs/LLD-groundscope-v2.md`, `~/.gstack/projects/sahajm99-groundscope/sahaj-v2.0-design-20260912-092340.md`, `docs/DECISIONS.md`.

## Global Constraints

- Free tier only. Groq is the judge model. No paid services.
- `requirements.txt` stays pinned. **Add** packages (in `requirements-dev.txt` for tooling), never upgrade existing pins.
- Fan-out cap: 3 sub-queries (`settings.max_subqueries = 3`). `relevance_distance_threshold` value untouched.
- Never loosen, skip, or delete a test or an eval to make CI pass. Integration tests must **fail** (not skip) in CI when the DB is unreachable (`CI=true`).
- MCP stdio subprocesses do **not** inherit the parent environment (mcp only forwards PATH/HOME-style vars). The registry must pass `env=dict(os.environ)` for local servers.
- Render free tier is 512 MB: the retrieval server must not load the embedding model when the orchestrator passes `query_embedding`.
- Conventional commits ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Local test DB: `postgresql://gs:gs@localhost:5433/groundscope` (docker container `gs-pg`, image `pgvector/pgvector:pg16`, already seeded with `data/sample.txt`). Run everything with `.venv/Scripts/python` on Windows.

```python
# mcp_servers/retrieval_server.py
"""groundscope-retrieval — Groundscope's retrieval as an MCP server (stdio).

Context tools: the orchestrator injects session_id; the LLM never chooses a tenant.
Structured JSON returns so the deterministic corrective-RAG gate can read `score`.
The orchestrator passes a precomputed `query_embedding` so this subprocess never
loads a second copy of the embedding model on a 512 MB host; external callers may
omit it and the server embeds lazily.
"""

from __future__ import annotations

import json

import _paths  # noqa: F401  (sys.path bootstrap)
from mcp.server.fastmcp import FastMCP

from app import storage

mcp = FastMCP("groundscope-retrieval")


def _embed(query: str) -> list[float]:
    from app.ingestion.embedder import get_embedder

    return get_embedder().embed([query])[0]


@mcp.tool()
def hybrid_search(
    session_id: str, query: str, limit: int = 6, query_embedding: list[float] | None = None
) -> str:
    """Hybrid (pgvector + BM25, RRF-fused) search over the session's documents plus the
    global corpus. Returns JSON {summary, score, sources:[{kind,label,detail,text}]};
    score is the best cosine distance (lower is closer)."""
    emb = query_embedding if query_embedding else _embed(query)
    hits, best = storage.hybrid_search(session_id, emb, query, limit=limit)
    sources = [
        {"kind": "doc", "label": f"{h.file_name} p.{h.page_number}", "detail": f"p.{h.page_number}", "text": h.text}
        for h in hits
    ]
    if not hits:
        summary = "No matching chunks in the uploaded documents."
    else:
        summary = (f"{len(hits)} chunks (vector+BM25, RRF-fused); best vector distance "
                   f"{best:.3f} from {hits[0].file_name} p.{hits[0].page_number}.")
    return json.dumps({"summary": summary, "score": best, "sources": sources})


@mcp.tool()
def metadata_query(session_id: str) -> str:
    """List the documents available to a session (uploads + global corpus).
    Returns JSON {summary, documents:[{file_name,pages,chunk_count,uploaded_at}]}."""
    docs = storage.list_documents(session_id)
    if not docs:
        summary = "No documents available in this session."
    else:
        summary = "Documents available — " + "; ".join(
            f"{d['file_name']}: {d['pages']} pages, {d['chunk_count']} chunks" for d in docs
        )
    return json.dumps({"summary": summary, "documents": docs})


if __name__ == "__main__":
    mcp.run(transport="stdio")
```

```python
# mcp_servers/web_server.py
"""groundscope-web — web grounding (Tavily) as an MCP server (stdio). Open tool."""

from __future__ import annotations

import json

try:
    import _paths  # noqa: F401
except ImportError:
    from mcp_servers import _paths  # noqa: F401
from mcp.server.fastmcp import FastMCP

from app.config import settings

mcp = FastMCP("groundscope-web")


def _client():
    from tavily import TavilyClient

    return TavilyClient(api_key=settings.tavily_api_key)


@mcp.tool()
def web_search(query: str, limit: int = 4) -> str:
    """Search the public web (Tavily). Returns JSON {summary, configured, sources:[{kind:'web',label,detail(url),text}]}."""
    if not settings.web_search_configured:
        return json.dumps({"summary": "Web search is not configured.", "configured": False, "sources": []})
    res = _client().search(query=query, max_results=limit, search_depth="basic")
    results = res.get("results", [])
    sources = [
        {"kind": "web", "label": r.get("title", "web result"), "detail": r.get("url", ""), "text": r.get("content", "")}
        for r in results
    ]
    summary = f"{len(results)} web results; top: {results[0].get('title', '')}." if results else "No web results found."
    return json.dumps({"summary": summary, "configured": True, "sources": sources})


if __name__ == "__main__":
    mcp.run(transport="stdio")
```

`app/agent/toolbus.py`:
```python
"""One tool bus over every MCP server in mcp.json.

Two tool classes (see LLD §1.3):
  context tools (hybrid_search, metadata_query): invoked by graph nodes with a
      server-injected session_id; for the ReAct worker they are exposed as
      session-scoped wrappers whose schema has NO session_id.
  open tools (everything else): the LLM may call them freely.
"""

from __future__ import annotations

import json
from collections.abc import Callable
from typing import Any

from langchain_core.tools import BaseTool, StructuredTool, ToolException
from pydantic import BaseModel, Field

CONTEXT_TOOLS = frozenset({"hybrid_search", "metadata_query"})


class ToolUnavailable(RuntimeError):
    pass


class ToolError(RuntimeError):
    pass


class _SearchArgs(BaseModel):
    query: str = Field(description="What to look for in the user's documents.")


class _NoArgs(BaseModel):
    pass


class ToolBus:
    def __init__(self, tools: list[BaseTool]):
        self._tools = {t.name: t for t in tools}

    def names(self) -> list[str]:
        return sorted(self._tools)

    def get(self, name: str) -> BaseTool | None:
        return self._tools.get(name)

    def open_tools(self) -> list[BaseTool]:
        return [t for n, t in self._tools.items() if n not in CONTEXT_TOOLS]

    async def call(self, name: str, **args: Any) -> dict:
        tool = self._tools.get(name)
        if tool is None:
            raise ToolUnavailable(name)
        try:
            raw = await tool.ainvoke(args)
        except ToolException as e:
            raise ToolError(f"{name}: {e}") from e
        if isinstance(raw, list):
            raw = "".join(str(x) for x in raw)
        try:
            return json.loads(raw)
        except (TypeError, ValueError) as e:
            raise ToolError(f"{name}: non-JSON result: {str(raw)[:120]}") from e

    def scoped_tools(self, session_id: str, embed: Callable[[str], list[float]]) -> list[BaseTool]:
        out: list[BaseTool] = []
        if "hybrid_search" in self._tools:
            async def search_documents(query: str) -> str:
                res = await self.call("hybrid_search", session_id=session_id, query=query, query_embedding=embed(query))
                return json.dumps(res)
            out.append(StructuredTool.from_function(
                coroutine=search_documents, name="search_documents", args_schema=_SearchArgs,
                description="Search the user's uploaded documents and the sample corpus (hybrid vector + keyword)."))
        if "metadata_query" in self._tools:
            async def list_documents() -> str:
                return json.dumps(await self.call("metadata_query", session_id=session_id))
            out.append(StructuredTool.from_function(
```

```python
import operator
from typing import Annotated
from langgraph.types import Send, StreamWriter

class S(TypedDict, total=False):
    session_id: str
    question: str
    step: int
    route: str
    subqueries: list[str]
    branches: Annotated[list, operator.add]
    collected: list
    best: Optional[float]
    web_ran: bool
    answer: str
    citations: list


class W(TypedDict):
    session_id: str
    question: str
    subquery: str
    branch: int
    total: int
    step: int


_PLAN_SYS = (
    'Return JSON {"route": "tools"|"knowledge", "subqueries": [..]}. '
    'Use "tools" ONLY if answering requires one of these action tools: {desc}. '
    'Use "knowledge" for questions about the user\'s documents or general facts. '
    'For "knowledge", split the question into at most {cap} independent sub-questions ONLY when it asks '
    'about several distinct things (e.g. "compare X and Y", "A and also B"); otherwise return a single '
    'item containing the question itself. Sub-questions must be self-contained search queries.'
)


def _clean_subqueries(raw, question: str, cap: int) -> list[str]:
    if not isinstance(raw, list):
        return [question]
    out = [s.strip() for s in raw if isinstance(s, str) and s.strip()]
    return out[:cap] if out else [question]


async def planner_node(state: S, writer: StreamWriter) -> S:
    q = state["question"]
    route, subqueries = "knowledge", [q]
    if is_metadata(q):
        route = "metadata"
    else:
        bus = await get_bus()
        desc = "; ".join(f"{t.name}: {(t.description or '')[:80]}" for t in bus.open_tools()) or "none"
        try:
            d = await asyncio.to_thread(complete_json, _PLAN_SYS.format(desc=desc, cap=settings.max_subqueries), q)
            route = d.get("route") if d.get("route") in ("tools", "knowledge") else "knowledge"
            subqueries = _clean_subqueries(d.get("subqueries"), q, settings.max_subqueries)
        except Exception:  # noqa: BLE001
            route, subqueries = "knowledge", [q]
        if route == "tools" and not bus.open_tools():
            route = "knowledge"
    summary = f"Planner routed to '{route}'."
    if route == "knowledge":
        summary += (f" {len(subqueries)} sub-queries: " + " | ".join(s[:60] for s in subqueries)) if len(subqueries) > 1 else " 1 sub-query."
    _emit(writer, state, type="decision", input=q[:200], summary=summary)
    return {"route": route, "subqueries": subqueries, "collected": [], "web_ran": False, "branches": []}


def _fanout(state: S) -> list[Send]:
    subs = state.get("subqueries") or [state["question"]]
    return [Send("retrieval_worker", {"session_id": state["session_id"], "question": state["question"],
                                      "subquery": sq, "branch": i, "total": len(subs), "step": 0})
            for i, sq in enumerate(subs)]


async def retrieval_worker(state: W, writer: StreamWriter) -> dict:
    sid, sq, b = state["session_id"], state["subquery"], state["branch"]
    bus = await get_bus()
    _emit(writer, state, type="tool_call", tool="hybrid_search", input=sq[:200], branch=b,
          summary=f"Searching your documents (vector + BM25) via MCP.")
    try:
        emb = await asyncio.to_thread(_embed, sq)
        res = await bus.call("hybrid_search", session_id=sid, query=sq, query_embedding=emb)
        sources = [_src(s) for s in res.get("sources", [])]
        best, summary = res.get("score"), res.get("summary", "")
    except Exception as e:  # noqa: BLE001
        _emit(writer, state, type="decision", branch=b,
              summary=f"Retrieval unavailable ({type(e).__name__}: {str(e)[:120]}); treating as no document matches.")
        sources, best, summary = [], None, "No document results."
    _emit(writer, state, type="tool_result", tool="hybrid_search", summary=summary, score=best, branch=b,
          preview=(sources[0].text[:220] + "…") if sources else None)
    grounded = bool(sources) and best is not None and best <= settings.relevance_distance_threshold
    if grounded or not settings.web_search_configured:
        if grounded:
            _emit(writer, state, type="decision", branch=b,
                  summary=f"Documents are relevant (distance {best:.3f} ≤ {settings.relevance_distance_threshold}).")
        return {"branches": [{"branch": b, "subquery": sq, "sources": sources, "best": best, "web": False}]}
    reason = (f"No documents (distance {best:.3f} > {settings.relevance_distance_threshold})."
              if best is not None else "No matching document chunks.")
    _emit(writer, state, type="decision", branch=b, summary=f"{reason} Falling back to the web.")
    _emit(writer, state, type="tool_call", tool="web_search", input=sq[:200], branch=b, summary="Searching the web via MCP.")
    try:
        res = await bus.call("web_search", query=sq)
        wsources = [_src(s) for s in res.get("sources", [])]
        wsummary = res.get("summary", "")
    except Exception as e:  # noqa: BLE001
        wsources, wsummary = [], f"Web search unavailable ({type(e).__name__})."
    _emit(writer, state, type="tool_result", tool="web_search", summary=wsummary, branch=b,
          links=[{"title": s.label, "url": s.detail} for s in wsources])
    return {"branches": [{"branch": b, "subquery": sq, "sources": wsources, "best": best, "web": True}]}


def aggregate_node(state: S, writer: StreamWriter) -> S:
    branches = sorted(state.get("branches", []), key=lambda x: x["branch"])
    seen, collected = set(), []
    for br in branches:
        for s in br["sources"]:
            k = (s.kind, s.label, s.detail)
            if k not in seen:
                seen.add(k)
                collected.append(s)
    doc_best = [br["best"] for br in branches if not br["web"] and br["best"] is not None]
    best = min(doc_best) if doc_best else None
    web_ran = any(br["web"] for br in branches)
    n_doc = sum(1 for s in collected if s.kind == "doc")
    n_web = sum(1 for s in collected if s.kind == "web")
    if len(branches) > 1:
        _emit(writer, state, type="decision", summary=f"Merged {len(branches)} branches: {n_doc} doc chunks, {n_web} web results (deduped).")
    return {"collected": collected, "best": best, "web_ran": web_ran}
```

## Review deltas (from the independent adversarial review, 2026-09-12)

These amend the tasks above; where they conflict, the delta wins.

1. **Task 4 — persistent retrieval session.** `mcp.json` entry for `groundscope-retrieval` gains `"keepalive": true`. `mcp_registry.load_mcp_tools()` becomes `mcp_registry.load_servers() -> ServerSet` where `ServerSet.tools: dict[server_name, list[BaseTool]]` and `ServerSet.close()`; keep-alive servers are entered through `MultiServerMCPClient.session(name)` inside a dedicated host task (`asyncio.create_task`) that enters an `AsyncExitStack`, loads tools with `load_mcp_tools(session)`, sets a ready event, and waits for a stop event (enter and exit happen in the same task, as anyio requires). Per-server try/except: a failing server logs a warning and is omitted; never cache an all-empty result (the next `get_bus()` retries). `ToolBus` exposes `servers() -> dict[str, list[str]]` for `/health` (`"mcp": {"groundscope-retrieval": ["hybrid_search", "metadata_query"], ...}`). If a keep-alive call fails at the transport level (not `ToolException`), the bus marks itself broken and `get_bus()` rebuilds once.
2. **Task 2 — server tools are `async def`** and run the DB work with `anyio.to_thread.run_sync`, so three concurrent branches do not serialize on the child's event loop. Clamp `limit` to `1..10`; validate `session_id` matches `^[A-Za-z0-9_-]{1,64}$` (else raise `ValueError`).
3. **Tasks 5/6 — sanitize and bound.** Trace summaries for tool failures show only `type(e).__name__`; the full error goes to `logging`. Every `bus.call` in a node is wrapped in `asyncio.wait_for(..., settings.tool_timeout_s)` (`config.py`: `tool_timeout_s: int = 60`). `tool_worker_node` puts at most the first 200 chars of a *successful* result in the trace and `"error: <ExceptionType>"` otherwise.
4. **Task 6 — `Send` mechanics (langgraph 0.2.39).** A node cannot return `Send`; the fan-out is a conditional edge (`g.add_conditional_edges("fanout", _fanout, ["retrieval_worker"])`) from a pass-through `fanout` node. Workers write only the reducer key `branches`. A raising worker cancels its siblings, so the worker catches everything and returns an error branch.
5. **Task 7 — no `innerHTML` for data.** Build steps with `document.createElement` + `textContent`; links get `href` via `setAttribute` after checking the scheme is `http(s)`.
